What is Cloud Computing?

Cloud computing is the delivery of computing services—including servers, storage, databases, networking, software, and analytics—over the Internet ("the cloud"). Instead of purchasing and maintaining physical servers or localized hard drives, users can access software applications and computing power on demand from cloud providers.

Cloud Services & Applications

Below are three popular cloud computing services and how they are used:

  • Google Drive: A cloud storage and file-sharing service used to back up files, access documents from any device, and collaborate in real time.
  • Amazon Web Services (AWS): A comprehensive cloud infrastructure platform used by companies to host websites, manage databases, and deploy virtual servers.
  • GitHub / VS Code Web: A cloud-based platform for source code management and development, allowing users to write, track, and store code online without local installations.

Key Advantages of Using Cloud Computing

  • Remote Accessibility: Access work and code from any internet-connected device.
  • Cost Efficiency: Reduces hardware acquisition and maintenance costs.
  • Scalability: Easily upgrade resources as storage or processing needs grow.
  • Automatic Synchronization: Saves and syncs changes to the cloud automatically.
